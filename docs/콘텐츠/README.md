# 콘텐츠 문서

홈페이지와 신청폼에 표시되는 문구의 작성 원칙, 용어와 화면별 확정 문구를 관리합니다.

## 문서 목록

- [카피 가이드](카피가이드.md): 문장 원칙, 말투, 용어와 금지 표현
- [화면별 카피](화면별카피.md): 신청폼 화면에 적용할 문구의 단일 원본
- [신청폼 UX 라이팅 개선 기획](신청폼-UX-라이팅-개선-기획.md): 현황 진단, 수정 우선순위와 검수 계획

## 관리 원칙

- 작성 원칙과 용어는 `카피가이드.md`에서 관리합니다.
- 실제 화면에 적용할 문구는 `화면별카피.md`에서만 확정합니다.
- 운영 사실이 정해지지 않은 문구에는 임의의 약속을 만들지 않고 `운영 확정 필요`로 표시합니다.
- 코드 반영 뒤에는 화면별 카피의 상태와 검수 결과를 함께 갱신합니다.
