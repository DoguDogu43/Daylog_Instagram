# 데이로그 신청폼 작업 문서

데이로그 Life Session 신청폼의 실제 구현 상태, 변경 기록, 검수 결과와 배포 절차를 관리합니다.

기획과 기준 문서는 `05-구현-명세`에 유지하고, 이 폴더에는 구현 이후 확인된 사실과 적용 이력을 기록합니다.

## 문서

- [노트·다이어리 UI 개선 기획안](노트-다이어리-UI-개선-기획안.md): 과거 UI 고도화 기획 기록, 노트 물성 아이디어 참고용
- [UI 수정방향 기획](UI-수정방향-기획.md): 과거 UI 개선 기획 기록, 현재 흐름의 기준 문서가 아님
- [구현 현황](구현-현황.md): 구현 범위, 화면 흐름, 기술 구조와 남은 운영 작업
- [Google Sheets 적용](Google-Sheets-적용.md): Vercel 환경변수와 통합 Apps Script 추가 절차
- [변경 기록](변경-기록.md): 요청별 UI와 코드 변경 내역
- [검수 결과](검수-결과.md): 자동 검사 결과와 운영 환경에서 확인할 항목
- [UI 디자인 피드백](UI-디자인-피드백.md): 과거 UI 검토 결과와 당시 개선 우선순위
