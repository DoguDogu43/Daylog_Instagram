## 1. 회의 개요 및 현재 UI 진단

### 1.1 배경 및 문제의식
데이로그(Daylog)는 고객이 자신의 일상을 평가받는 것이 아니라, 있는 그대로의 하루를 돌아보고 전문 코치와 함께 나다운 삶의 루틴을 설계해 나가는 1:1 라이프 디자인 서비스입니다.

최근 개편을 통해 좌우 2열 분할의 카드 짤림(Clipping) 및 좁은 가로 폭 문제를 단일 스프링 노트(`max-width: 820px`)로 해결하고, 02단계 시간 선택을 직접 텍스트 입력으로 전환하여 가독성과 사용성을 크게 개선했습니다.

이 시점에서 프로덕트 팀은 다음 질문에 집중했습니다:
> **"사용자가 신청할 때, 단순한 '웹 설문지'가 아니라 '내 다이어리를 차분하게 한 장씩 적어 내려가는 따뜻한 아날로그 경험'을 어떻게 더 깊이 느낄 수 있는가?"**

### 1.2 As-Is(현재) vs To-Be(발전 방향) 종합 진단

| 구분 | 현재 상태 (As-Is) | 개선 목표 (To-Be) |
| :--- | :--- | :--- |
| **전체 공간감** | 평면적인 웹 카드 형태의 노트 | 은은한 조명 아래 책상(Desk) 위에 놓인 입체적인 양장/스프링 다이어리 |
| **기록 피드백** | 선택 시 단순 노란 배경 및 라디오 체크 | 만년필 잉크가 스며들고 형광펜으로 부드럽게 칠해지는 필기 인터랙션 |
| **페이지 넘김** | 단순 페이드/수직 슬라이드 모션 | 가벼운 종이 곡면과 그림자가 살아있는 정갈한 책장 넘김(Page Turn) |
| **진행 인지** | 일반적인 웹 프로그레스 바 | 다이어리 상단 인덱스 탭과 페이지 스탬프를 통한 기록 누적감 |
| **질문 톤앤매너** | 시스템이 묻고 사용자가 답하는 설문 형태 | "나의 이야기"를 코치에게 편안하게 털어놓는 1인칭 자기 대화형 서사 |

## 2. 4대 핵심 개선 기둥 (Pillars)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   DAYLOG LIFE NOTE METAPHOR SYSTEM                     │
├───────────────────┬────────────────────┬───────────────────────────────┤
│ 1. 물성과 질감    │ 2. 인터랙션 & 모션 │ 3. 서사와 심리                │
│ (Materiality)     │ (Interaction)      │ (Narrative)                   │
├───────────────────┼────────────────────┼───────────────────────────────┤
│ • 웜 아이보리 속지│ • 형광펜 드로잉    │ • 1인칭 기록 문장             │
│ • 은은한 줄눈선   │ • 페이지 넘김 모션 │ • 판단 없는 다정한 질문       │
│ • 메탈 링 & 스탬프│ • 만년필 잉크 효과 │ • 초안 완성 성취감            │
└───────────────────┴────────────────────┴───────────────────────────────┘
```

### Pillar 1. 물성(Materiality)과 시각적 디테일 강화
1. **정갈한 종이 속지(Paper Texture) 디테일**:
   - 기획서 공식 토큰인 Warm Ivory (`#FFF9EF`) 베이스에 눈이 편안한 은은한 가로 줄눈(Ruled Line)과 왼쪽 레드 마진선을 유지.
   - 단색 평면이 아닌, 실제 종이의 미세한 온도를 느낄 수 있는 다층 종이 스택(Paper Layer) 그림자 효과 적용.
2. **다이어리 오브젝트 요소**:
   - 상단 와이어-오(Wire-O) 제본 코일에 은은한 광택 그라디언트 적용.
   - 상단 인덱스 탭(`[01 리듬]`, `[02 온도]`, ...)을 실제 다이어리 견출지 라벨 질감으로 마감.
   - 완료 화면에는 잉크가 꾹 찍힌 듯한 세이지 그린 도장(CONFIRMED STAMP) 디테일 유지.

---

### Pillar 2. 아날로그 인터랙션 & 모션 (Motion)
1. **페이지 넘김(Page Turn) 트랜지션**:
   - '다음 장으로 넘기기' 클릭 시 오른쪽에서 왼쪽으로 부드러운 종이 그림자가 지나가며 새로운 페이지가 펼쳐지는 240ms 모션.
2. **형광펜 & 체크 마이크로 인터랙션**:
   - 카드 선택 시 정적인 색상 변화 대신, 왼쪽에서 오른쪽으로 형광펜이 슥 그어지는 듯한 CSS 드로잉 애니메이션(`highlightSweep`).
3. **텍스트 직접 입력 시 필기 감성**:
   - 02단계 시간/순간 입력창 포커스 시 부드러운 잉크 블루 포커스 링 적용.
   - 빠른 힌트 칩 탭 시 텍스트가 인풋에 자연스럽게 채워지는 마이크로 피드백.

---

### Pillar 3. 사용자 심리와 기록 서사 (Narrative)
1. **평가가 아닌 자기 기록(Self-Reflection)으로의 전환**:
   - "테스트를 통과한다"는 느낌을 완전히 배제하고, "오늘 나의 하루를 한 장에 정리해본다"는 안도감 형성.
2. **1인칭 문장 요약 (LIFE NOTE Draft)**:
   - 각 질문에 선택한 단편적 데이터가 최종 요약 단계에서 **"나는 아침부터 움직일 때 리듬이 살아나며, 오후 3시 회의 후에 가장 지칩니다..."**와 같은 따뜻한 1인칭 완성 문장으로 자동 엮임.
   - 내가 쓴 다이어리 한 페이지를 완성했다는 성취감 제공.

---

### Pillar 4. 모바일 & 가독성 최적화 (Usability)
1. **한 손 조작(Thumb Zone) 최적화**:
   - 모바일 뷰포트(375px~390px)에서 이전/다음 버튼을 하단 엄지손가락 영역에 넉넉한 48px 이상 터치 타겟으로 배치.
2. **320px 소형 기기 무결점 대응**:
   - 화면 폭이 좁은 초소형 기기에서도 텍스트 잘림이나 줄바꿈 어색함이 없도록 유동 폰트(`clamp()`) 및 여백 비율 최적화.
3. **가상 키보드 가림 방지**:
   - 02단계 텍스트 입력 및 연락처 입력 시 모바일 가상 키보드가 활성화되어도 입력창과 제출 버튼이 화면 밖으로 밀려나지 않도록 `scrollIntoView` 정밀 제어.
