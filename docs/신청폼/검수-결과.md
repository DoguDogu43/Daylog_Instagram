## 구현 확인

- [x] 하단 코치 이미지가 렌더링되지 않습니다.
- [x] 4개 질문을 이전·다음으로 이동할 수 있습니다.
- [x] 필수 선택 전 다음 단계 이동을 막고 한국어 오류를 표시합니다.
- [x] 편안한 순간과 버거운 순간은 기본값 없이 사용자가 1~100자의 텍스트로 입력합니다.
- [x] 질문 화면에는 선택 답변 노트 미리보기가 렌더링되지 않습니다.
- [x] 4단계 완료 뒤 별도 요약 없이 연락 신청으로 이동합니다.
- [x] 화면에 원형 하루 지도와 관련 문구가 표시되지 않습니다.
- [x] 인트로, 질문, 연락 신청과 완료 화면이 노트형 시각 언어를 유지합니다.
- [x] 1~3개의 변화 영역과 첫 우선 영역을 구분합니다.
- [x] `togetherStyle` 질문 없이 돌볼 습관에서 연락 신청으로 직결됩니다.
- [x] 첫 화면에서 3분 기록 후 오프라인 Life Session을 신청한다는 목적을 확인할 수 있습니다.
- [x] 1280×720 화면에서 시작 CTA가 초기 화면 안에 표시됩니다.
- [x] 390×844 브라우저 뷰포트에서 가로 잘림 없이 자연스럽게 세로 스크롤할 수 있습니다.
- [x] 320×568 브라우저 뷰포트에서 가로 잘림 없이 질문과 CTA에 접근할 수 있습니다.
- [x] 데스크톱 질문 화면에서 로고, 진행선, 제목, 카드와 버튼이 같은 본문 기준선에 맞습니다.
- [x] 모바일 질문 화면에서 로고와 질문 본문의 왼쪽 기준선이 일치합니다.
- [x] 700px 이하 연락 화면에서도 필수 입력과 제출 CTA에 세로 스크롤로 접근할 수 있습니다.
- [x] 희망 요일, 희망 시간대와 추가 이야기를 비워도 제출 요청을 진행할 수 있습니다.
- [x] 선택 일정과 메모는 기본적으로 접힌 상태로 표시됩니다.
- [x] 필수 연락 입력 오류 시 해당 입력으로 포커스가 이동합니다.
- [x] 퍼널은 `together_style_selected`와 `life_note_viewed` 없이 4단계 다음 `application_started`로 이어집니다.
- [x] 신청 스키마는 `daylog-life-session-v2`이며 에너지 순간을 1~100자 문자열로 처리합니다.
- [x] 제출 실패 시 입력 상태를 유지합니다.
- [x] 개인정보는 브라우저 저장소에 넣지 않습니다.
- [x] 퍼널 요청에는 답변과 연락처가 포함되지 않습니다.
- [x] Vercel API가 외부 입력을 실행 시에 재검증합니다.
