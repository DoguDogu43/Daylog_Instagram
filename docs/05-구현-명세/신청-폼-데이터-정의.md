# 데이로그 신청 폼 데이터 정의

## 문서 목적

신청 경험에서 수집하는 값, 코드, 검증 규칙과 Google Sheets 저장 항목을 정의합니다.

화면 문구는 바뀔 수 있지만 데이터 코드는 의미가 달라지지 않는 한 유지합니다. 코드나 필드 의미가 변경되면 `schemaVersion`을 올립니다.

## 수집 원칙

- 온라인 신청은 고객을 진단하는 도구가 아닙니다.
- 직접 만남을 준비하는 데 필요한 최소 정보만 수집합니다.
- 오프라인 인터뷰 조율에 필요한 신청자 정보와 가능 일정만 수집합니다.
- 생활 탐색 답변은 짧게 받으며, 에너지 순간 두 항목만 각각 1~100자의 자유 텍스트를 요구합니다.
- 생활 탐색 답변과 연락처를 구분합니다.
- 퍼널 이벤트에는 생활 답변과 개인정보를 넣지 않습니다.
- 고객이 선택한 답변을 점수나 성격 유형으로 변환하지 않습니다.
- 서버에서 허용값을 다시 검증하고 표시 문구를 결정합니다.
- Google Sheets에는 운영자가 읽는 문구와 분석을 위한 코드 원본을 함께 남깁니다.

## 현재 설계 범위

신청 경험은 다음 데이터 그룹으로 구성합니다.

1. 신청 세션과 접수 식별자
2. LIFE NOTE 생활 탐색 답변
3. Life Session 연락 및 일정 정보
4. 개인정보 동의
5. 접수 경로와 캠페인 정보
6. 폼 및 데이터 스키마 버전

상세 주소, 성별과 직업은 수집하지 않습니다. 장소 조율에는 거주지 주변 역만 사용합니다.

## 장면별 필드

| 장면 | 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| Scene 01 | `dailyRhythm` | enum | 필수 | 현재 하루의 기본 리듬 |
| Scene 02 | `comfortableTime` | string | 필수 | 가장 편안한 시간·순간 텍스트 (1~100자) |
| Scene 02 | `difficultTime` | string | 필수 | 가장 버거운 시간·순간 텍스트 (1~100자) |
| Scene 03 | `pastPattern` | enum | 필수 | 과거에 무언가를 지속하도록 도운 조건 |
| Scene 04 | `changeAreas` | enum[] | 필수 | 바꾸고 싶은 생활 영역을 1→2→3순위 순서로 저장 |
| 신청 | `displayName` | string | 필수 | 신청자 이름 |
| 신청 | `age` | integer | 필수 | 현재 나이, 1~120 |
| 신청 | `phoneNumber` | string | 필수 | `010-0000-0000` 형식 전화번호 |
| 신청 | `nearbyStation` | string | 필수 | 상세 주소가 아닌 거주지 주변 역 |
| 일정 | `preferredDays` | enum[] | 필수 | 인터뷰 가능한 요일 1개 이상 |
| 일정 | `preferredPeriods` | enum[] | 필수 | 인터뷰 가능한 시간대 1개 이상 |
| 동의 | `privacyConsent` | boolean | 필수 | 개인정보 수집·이용 동의 |

## 개인정보 수집 및 이용 고지

- 수집 항목: 이름, 나이, 전화번호, 거주지 주변 역, 인터뷰 가능 요일 및 시간대, LIFE NOTE 응답
- 수집 목적: 체험 프로그램 신청 접수, 참여자 확인, 인터뷰 일정 안내 및 세션 준비
- 보유 기간: 신청일로부터 3개월 후 파기
- `privacyConsent`가 `true`가 아니면 신청을 접수하지 않습니다.

## 하루 리듬 코드

| 코드 | 화면 문구 | Sheets 표시값 |
| --- | --- | --- |
| `morning_active` | 아침부터 움직이는 하루 | 아침 중심 |
| `daytime_focus` | 낮에 집중되는 하루 | 낮 중심 |
| `evening_important` | 저녁이 중요한 하루 | 저녁 중심 |
| `irregular_daily` | 매일 조금씩 다른 하루 | 불규칙 |

## 시간 및 에너지 순간 필드

`comfortableTime`과 `difficultTime`은 사용자가 자신의 일상에서 편안한 때와 버거운 때를 자유롭게 표현할 수 있도록 텍스트 문자열(1~100자)로 저장합니다.

- 입력 방식: 직접 타이핑 입력창 및 빠른 입력 예시 칩 제공
- 예시: `아침 7시 기상 직후`, `오전 10시 몰입 시간`, `오후 3시 회의 끝난 뒤`, `밤 11시 침대에서 폰 볼 때`
- 두 항목 모두 1자 이상의 유효한 텍스트 입력을 필수로 합니다.

## 과거 지속 방식 코드

| 코드 | 화면 문구 | Sheets 표시값 |
| --- | --- | --- |
| `solo_focus` | 혼자 집중할 때 잘 이어갔어요. | 혼자 집중 |
| `together_commitment` | 누군가와 함께할 때 오래갔어요. | 함께하는 약속 |
| `fixed_time_place` | 시간과 장소가 정해져 있을 때 편했어요. | 정해진 시간·장소 |
| `meaning_or_fun` | 즐거움이나 의미가 있을 때 움직였어요. | 즐거움·의미 |
| `unknown` | 아직 잘 모르겠어요. | 아직 모름 |

| `meal` | 식사 | 식사 |
| `exercise` | 운동 | 운동 |
| `smartphone` | 스마트폰 | 스마트폰 |

검증 규칙:

- `changeAreas`는 1~3개만 허용합니다.
- 중복 코드를 허용하지 않습니다.
- 배열 순서를 순위로 사용하며 별도 1순위 필드를 두지 않습니다.

## 신청자 정보 검증

- `age`는 1~120 범위의 정수만 허용합니다.
- `phoneNumber`는 `010-0000-0000` 형식만 허용합니다.
- `nearbyStation`은 앞뒤 공백을 제거한 1~50자 문자열입니다.

| 코드 | 표시값 |
| --- | --- |
| `mon` | 월 |
| `tue` | 화 |
| `wed` | 수 |

| `afternoon` | 오후 12시~6시 |
| `evening` | 저녁 6시~9시 |
| `flexible` | 상관없음 |

검증 규칙:

- 1~3개를 선택합니다.
- 중복을 허용하지 않습니다.
- `flexible`을 선택하면 다른 시간대를 함께 선택할 수 없습니다.

## 문자열 길이

| 필드 | 최소 | 최대 | 비고 |
| --- | ---: | ---: | --- |
| `displayName` | 1 | 50 | 앞뒤 공백 제거 |
| `phoneNumber` | 13 | 13 | `010-0000-0000` 형식 |
| `nearbyStation` | 1 | 50 | 앞뒤 공백 제거 |
| `comfortableTime` | 1 | 100 | 앞뒤 공백 제거 |
| `difficultTime` | 1 | 100 | 앞뒤 공백 제거 |
| `source` | 1 | 50 | 서버가 기본값 설정 |
| UTM 항목 | 0 | 100 | 허용 문자와 길이 제한 |

사용자 입력 문자열은 Google Sheets에 저장하기 전에 수식 주입 방지 처리를 거칩니다.

## 식별자

### 익명 세션 ID

형식:

```text
DAYLOG-S-550E8400-E29B-41D4-A716-446655440000
```

규칙:

- 신청 경험을 시작할 때 생성합니다.
- 접두어는 `DAYLOG-S-`입니다.
- 뒤에는 대문자 UUID를 사용합니다.
- 퍼널 이벤트 식별에만 사용합니다.
- 연락처나 생활 답변을 포함하지 않습니다.

### 접수번호

형식:

```text
DAYLOG-550E8400-E29B-41D4-A716-446655440000
```

규칙:

- 신청 정보 입력을 시작할 때 한 번 생성합니다.
- 제출 재시도에서도 같은 접수번호를 사용합니다.
- Google Sheets 중복 저장 방지 키로 사용합니다.

### 이벤트 ID

형식:

```text
DAYLOG-S-550E8400-E29B-41D4-A716-446655440000:daily_rhythm_selected
```

같은 세션의 같은 단계는 한 번만 집계합니다.

## 메타데이터

| 필드 | 값 또는 규칙 |
| --- | --- |
| `source` | 기본값 `daylog_web` |
| `utmSource` | 선택, 최대 100자 |
| `utmMedium` | 선택, 최대 100자 |
| `utmCampaign` | 선택, 최대 100자 |
| `formVersion` | 화면·질문 버전, 현재 `2026.08.8` |
| `schemaVersion` | 데이터 구조 버전, `daylog-life-session-v3` |

개인 답변, 이름과 연락처는 분석 이벤트에 포함하지 않습니다.

## 브라우저에서 서버로 보내는 신청 데이터

브라우저는 Apps Script 비밀값과 `formType`을 알지 않습니다. 다음 데이터만 같은 출처의 서버 API로 보냅니다.

```json
{
  "action": "submit",
  "requestId": "DAYLOG-550E8400-E29B-41D4-A716-446655440000",
  "sessionId": "DAYLOG-S-550E8400-E29B-41D4-A716-446655440000",
  "dailyRhythm": "evening_important",
  "comfortableTime": "아침 7시 기상 직후",
  "difficultTime": "오후 3시 회의가 끝난 뒤",
  "pastPattern": "together_commitment",
  "changeAreas": ["sleep", "exercise"],
  "displayName": "홍길동",
  "age": 29,
  "phoneNumber": "010-1234-5678",
  "nearbyStation": "2호선 성수역",
  "preferredDays": ["sat", "sun"],
  "preferredPeriods": ["afternoon"],
  "privacyConsent": true,
  "source": "daylog_web",
  "utmSource": "instagram",
  "utmMedium": "social",
  "utmCampaign": "life_session_launch",
  "formVersion": "2026.08.8",
  "schemaVersion": "daylog-life-session-v3",
  "website": ""
}
```

`website`는 실제 사용자에게 보이지 않는 스팸 방지용 honeypot 필드입니다.

## 서버에서 Apps Script로 보내는 추가값

Vercel 서버는 환경변수에서 다음 값을 읽어 요청에 추가합니다.

```json
{
  "formType": "daylog_life_session",
  "secret": "서버 환경변수의 비밀값"
}
```

비밀값은 브라우저 응답, 로그와 Google Sheets에 기록하지 않습니다.

## Google Sheets 신청응답 열

탭 이름:

```text
데이로그_라이프세션_신청응답
```

| 순서 | 열 이름 | 원본 또는 생성 방식 |
| ---: | --- | --- |
| 1 | 접수시각 | Apps Script의 `new Date()` |
| 2 | 접수번호 | `requestId` |
| 3 | 신청 상태 | 기본값 `신규` |
| 4 | 이름 | `displayName` |
| 5 | 나이 | `age` |
| 6 | 전화번호 | `phoneNumber` |
| 7 | 거주지 주변 역 | `nearbyStation` |
| 8 | 인터뷰 가능 요일 | `preferredDays` 표시값 결합 |
| 9 | 인터뷰 가능 시간대 | `preferredPeriods` 표시값 결합 |
| 10 | 하루 리듬 | `dailyRhythm` 표시값 |
| 11 | 편안한 시간 | 검증된 `comfortableTime` 순간 문자열 |
| 12 | 힘든 시간 | 검증된 `difficultTime` 순간 문자열 |
| 13 | 지속 방식 | `pastPattern` 표시값 |
| 14 | 변화 영역 순위 | `1순위 수면, 2순위 운동` 형식 |
| 15 | 개인정보 동의 | `동의` |
| 16 | 접수 경로 | `source` |
| 17 | UTM 소스 | `utmSource` |
| 18 | UTM 매체 | `utmMedium` |
| 19 | UTM 캠페인 | `utmCampaign` |
| 20 | 익명 세션 ID | `sessionId` |
| 21 | 폼 버전 | `formVersion` |
| 22 | 스키마 버전 | `schemaVersion` |
| 23 | 응답 코드 JSON | 서버 검증을 통과한 생활 답변만 JSON으로 저장 |

표시값은 Apps Script의 허용값 매핑에서 생성합니다. 브라우저가 보낸 임의의 표시 문구를 그대로 신뢰하지 않습니다.

신규 v3 탭은 위 23열 구조를 사용합니다. 기존 탭은 열을 삭제하지 않고 누락된 v3 헤더만 끝에 추가합니다. 새 행은 헤더명을 기준으로 정렬하며 과거 전용 열에는 빈 값을 기록합니다.

## 응답 코드 JSON

운영자가 읽는 열과 별도로 원래 코드값을 유지합니다.

```json
{
  "dailyRhythm": "evening_important",
  "comfortableTime": "아침 7시 기상 직후",
  "difficultTime": "오후 3시 회의가 끝난 뒤",
  "pastPattern": "together_commitment",
  "changeAreas": ["sleep", "exercise"]
}
```

개인정보와 연락처는 이 JSON에 중복 저장하지 않습니다.
