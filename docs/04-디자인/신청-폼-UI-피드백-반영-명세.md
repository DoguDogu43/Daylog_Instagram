# 신청폼 UI 피드백 반영 디자인 수정 명세

- 작성일: 2026-09-01
- 상태: 구현 및 검수 완료
- 구현 반영일: 2026-09-01
- 적용 대상: 데이로그 LIFE NOTE 신청폼 Page 00~06 및 완료 화면

## 문서 목적

이 문서는 2026-09-01 디자인 피드백을 현재 LIFE NOTE 디자인에 반영하기 위한 구현 기준입니다. 기존 화면 구조와 질문 흐름은 유지하고, 노트 안쪽 여백, 텍스트 위계, 페이지 내비게이터, 활성 상태, 전진 버튼과 페이지별 컬러 일관성을 수정합니다.

이 문서에 명시된 변경 범위는 [신청 경험 디자인](신청-폼-디자인.md)의 관련 기준보다 우선합니다. 데이터 구조, 질문 순서와 제출 흐름은 변경하지 않습니다.

## 수정 목표

1. 모든 콘텐츠가 노트의 붉은 세로선과 첫 번째 가로줄 안쪽에서 시작하게 합니다.
2. 메인 텍스트와 서브 텍스트를 분리해 정보 위계를 더 분명하게 만듭니다.
3. 페이지 내비게이터를 작은 포스트잇이 붙은 모습으로 바꿉니다.
4. 현재 페이지와 다음 행동이 첫눈에 구분되게 합니다.
5. Page 00, Page 02, Page 05, Page 06의 시각적 불일치를 정리합니다.

## 컬러 역할 수정

기존 Deep Navy, Growth Yellow, Warm Ivory와 Sage Green은 유지합니다. 분홍색은 이번 피드백을 반영하기 위한 **형광펜 및 현재 위치 전용 보조색**으로만 추가합니다.

| 역할 | 값 | 사용 기준 |
| --- | --- | --- |
| Pink Highlighter | `#FF6F9C` | 표지 형광펜 효과에 44% 투명도로 사용 |
| Active Post-it | `#FF8FB1` | 현재 페이지 내비게이터의 불투명 배경 |
| Default Post-it | `#F7E5A1` | 이동 가능한 비활성 페이지 내비게이터 |
| Locked Post-it | `#EDE1CF` | 아직 이동할 수 없는 페이지 내비게이터 |
| Forward Action | `#F5B82E` | 다음 장으로 이동하는 버튼 배경 |
| Input Surface | `#FFFEFB` | Page 02 입력창의 불투명 배경 |

분홍색은 장식 전반에 확장하지 않습니다. 선택 카드의 강조, 일반 안내 박스와 제출 완료 상태에는 기존 컬러 역할을 유지합니다. Sage Green은 신청 완료 도장과 완료 메시지처럼 실제 완료 의미가 있는 곳에서만 사용합니다.

## 공통 레이아웃

### 노트 안쪽 여백

콘텐츠는 반드시 붉은 세로선 오른쪽에서 시작하고, 첫 번째 가로줄 아래에서 시작해야 합니다. `padding`과 붉은 선의 위치는 다음 값을 기준으로 합니다.

| 화면 너비 | 붉은 선의 왼쪽 위치 | 콘텐츠 `padding` 상·우·하·좌 | 붉은 선과 콘텐츠 간격 |
| --- | ---: | --- | ---: |
| 769px 이상 | 48px | `48px 48px 48px 72px` | 24px |
| 481~768px | 28px | `40px 24px 36px 48px` | 20px |
| 361~480px | 18px | `40px 16px 28px 32px` | 14px |
| 360px 이하 | 14px | `36px 12px 24px 28px` | 14px |

- 노트의 첫 가로줄이 상단에서 31~32px에 있다면 콘텐츠는 최소 36px 이후에 시작합니다.
- 360px 이하에서도 붉은 세로선을 숨기지 않습니다.
- 카드나 입력창이 콘텐츠 영역을 벗어나 붉은 선과 겹치지 않게 모든 자식 요소에 `min-width: 0`과 `max-width: 100%`를 유지합니다.
- 화면 높이가 낮아져도 좌우 여백은 유지하고, 필요한 경우 세로 스크롤을 허용합니다.

### 메인 텍스트와 서브 텍스트 간격

메인 문장과 설명 문장의 간격은 기존보다 최소 4px 넓힙니다.

| 대상 | 현재 | 수정 |
| --- | ---: | ---: |
| 표지 제목 ↔ 설명 | 12px | 16px |
| 질문 제목 ↔ 설명 | 6px | 12px |
| Page 05 제목 그룹 | 7px | 12px |
| Page 06 제목 ↔ 설명 | 6px | 12px |
| 입력 그룹 제목 ↔ 설명 | 2px | 6px |
| Page 02 입력 카드 제목 ↔ 설명 | -4px 상단 여백 | 0px 상단 여백 |

- 제목과 설명을 같은 컨테이너의 `gap`으로 관리하고, 가능한 한 음수 `margin`을 사용하지 않습니다.
- 360px 이하에서도 제목과 설명 간격은 최소 10px을 유지합니다.
- 간격 확대 때문에 주요 CTA가 화면 밖으로 밀릴 경우 텍스트 간격이 아니라 장식 영역과 카드 내부 여백을 먼저 줄입니다.

## 페이지 내비게이터

### 포스트잇 형태

기존의 어두운 탭 형태를 작은 포스트잇 묶음으로 바꿉니다.

- 모서리 반경은 4px로 줄여 종이 조각처럼 보이게 합니다.
- 탭마다 `-1deg`, `0.8deg`, `-0.6deg` 범위의 고정 회전을 번갈아 사용합니다.
- 오른쪽 아래에 7~9px 크기의 접힌 모서리를 추가합니다.
- 기본 그림자는 `0 3px 0 rgb(14 22 38 / 18%), 0 7px 12px rgb(0 0 0 / 18%)`를 사용합니다.
- 포스트잇 사이 간격은 8px, 최소 터치 높이는 44px을 유지합니다.
- 탭이 화면 너비를 넘으면 한 줄 가로 스크롤을 유지하고 현재 탭을 중앙에 가깝게 자동 노출합니다.

### 상태 표현

| 상태 | 배경 | 테두리·형태 | 텍스트 |
| --- | --- | --- | --- |
| 이동 가능 | `#F7E5A1` | 1px 반투명 네이비, 미세 회전 | Deep Navy |
| 현재 페이지 | `#FF8FB1` | 2px Deep Navy, 회전 0, `translateY(-4px)`, 더 강한 그림자 | Deep Navy, 900 굵기 |
| 잠김 | `#EDE1CF` | 1px Soft Beige, 그림자 축소 | Charcoal 65% |
| 키보드 포커스 | 상태색 유지 | 3px Deep Navy 외곽선, 3px 간격 | 상태에 따름 |

- 현재 상태는 색 외에도 굵은 테두리, 위치, 글자 굵기와 `aria-current="page"`로 구분합니다.
- 잠김 상태는 `disabled` 속성을 유지하고 포인터 상호작용을 제공하지 않습니다.
- Page 05와 Page 06에도 Page 00~04와 완전히 같은 내비게이터 상태 규칙을 적용합니다.
- 특정 페이지에서만 내비게이터 배경이나 글자색을 녹색으로 바꾸지 않습니다.

## 화면별 수정 명세

### Page 00. 표지

- `하루를 설계해볼게요.`의 형광펜 효과를 Growth Yellow에서 Pink Highlighter로 변경합니다.
- 형광펜 면은 `#FF6F9C` 44% 투명도, 높이 42~45%를 사용합니다.
- 글자색은 Deep Navy를 유지하고 형광펜 면은 글자의 아래쪽 절반에만 겹칩니다.
- 제목과 설명 간격을 16px로 늘립니다.
- 시작 CTA는 Deep Navy를 유지합니다.

### Page 01·03·04. 선택 화면

- 현재 선택 상태의 배경은 Growth Yellow 24%(`rgb(245 184 46 / 24%)`)로 높이고 2px Deep Navy 테두리를 사용합니다.
- 색상만으로 상태를 표현하지 않고 라디오·체크 표시와 순위 숫자를 함께 유지합니다.
- 질문 제목과 설명 간격은 12px을 사용합니다.
- 다음 버튼은 Growth Yellow 전진 버튼 스타일을 적용합니다.

### Page 02. 하루의 온도

- 두 텍스트 입력창의 배경을 `#FFFEFB` 단색으로 변경합니다.
- 입력창의 `background-image`는 모든 상태에서 `none`으로 설정해 노트 가로줄이나 부모 배경 이미지가 비치지 않게 합니다.
- 입력 카드 자체도 불투명한 `#FFFFFF` 면을 유지합니다.
- Focus 시 배경은 `#FFFFFF`, 테두리는 Deep Navy를 사용합니다.
- 입력값 유무와 관계없이 입력창 뒤로 노트 배경이 보여서는 안 됩니다.
- 카드 제목과 설명 사이의 음수 여백을 제거하고 최소 4px의 실제 간격을 확보합니다.

### Page 05. LIFE SESSION 안내

- 내비게이터는 앞 페이지와 같은 포스트잇 규칙을 사용합니다.
- `60 MINUTES · 1:1 OFFLINE` 보조 텍스트의 Sage Green을 제거하고 Ink Secondary `#4A5568`로 변경합니다.
- 후속 만남 안내 박스의 녹색 면은 Soft Beige 또는 Warm Ivory 계열로 변경하고 Deep Navy 텍스트를 사용합니다.
- 세이지 그린은 이 페이지에서 사용하지 않습니다.
- 제목 그룹 간격은 12px로 통일합니다.
- 신청 정보로 이동하는 전진 버튼은 Growth Yellow 스타일을 적용합니다.

### Page 06. 신청 정보

- 내비게이터는 앞 페이지와 같은 포스트잇 규칙을 사용합니다.
- `APPLICATION · PAGE 06` 보조 텍스트의 Sage Green을 제거하고 Ink Secondary `#4A5568`로 변경합니다.
- 제목, 설명과 입력 그룹의 간격 규칙을 Page 01~05와 동일하게 맞춥니다.
- 세이지 그린은 이 페이지에서 사용하지 않습니다.
- 최종 `LIFE SESSION 신청하기` 버튼은 Deep Navy를 유지합니다.

### 완료 화면

- 완료 도장과 완료 상태 문구에는 Sage Green을 유지합니다.
- Sage Green을 완료 의미로 제한해 Page 05·06과 명확한 상태 차이를 만듭니다.

## 반응형 및 접근성 기준

- 320px, 375px, 768px와 1280px 너비에서 붉은 선과 콘텐츠가 겹치지 않아야 합니다.
- 1280×720에서 질문, 선택 영역과 전진 버튼을 자연스러운 한 번의 시선 흐름으로 확인할 수 있어야 합니다.
- 내비게이터와 버튼의 터치 영역은 최소 44×44px을 유지합니다.
- 분홍색과 노란색 면 위에는 Deep Navy 텍스트를 사용합니다.
- 현재 페이지, 선택, 비활성과 완료 상태를 색만으로 구분하지 않습니다.
- `prefers-reduced-motion`에서는 포스트잇 위치 이동과 형광펜 애니메이션을 즉시 완료 상태로 표시합니다.
- 가로 스크롤 내비게이터는 키보드 포커스 순서를 Page 00→06으로 유지합니다.
