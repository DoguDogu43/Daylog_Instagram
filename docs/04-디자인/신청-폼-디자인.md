# 데이로그 신청 경험 디자인

## 디자인 결정

신청폼은 루틴을 진단하는 도구가 아니라 **내 하루를 짧게 정리해보는 첫 번째 노트**처럼 보여야 합니다.

고객은 평범한 설문을 통과하는 대신 짧은 선택으로 자신의 하루를 돌아봅니다. 질문 단계에서는 질문과 선택에만 집중하고, 선택한 답변은 마지막에 첫 만남에서 함께 이어 쓸 `나의 하루 초안`으로 완성됩니다.

> 신청폼 자체가 데이로그와 처음 함께 쓰는 하루 기록이어야 합니다.

## 신청 편의 원칙

노트는 브랜드를 느끼게 하는 시각적 경험이고, 실제 사용은 빠르고 편한 신청폼이어야 합니다.

- 사용자가 문장을 직접 작성하지 않아도 선택한 답변이 노트 문장으로 자동 변환됩니다.
- 한 화면에는 한 가지 질문과 하나의 분명한 다음 행동만 보여줍니다.
- 필수 자유 입력은 사용하지 않습니다.
- 생활 탐색은 5개의 짧은 질문으로 끝내고 전체 목표 시간은 약 3분입니다.
- 연락 신청의 필수 항목은 이름·호칭, 연락 방법, 연락처와 개인정보 동의로 제한합니다.
- 희망 요일, 희망 시간대와 추가 이야기는 선택 입력으로 두고 연락 과정에서 보완할 수 있게 합니다.
- 장식용 종이, 메모와 노트는 질문, 입력, 오류와 CTA보다 앞에 나오지 않습니다.
- 이전 단계로 돌아가 답변을 고칠 수 있으며 수정한 내용은 마지막 노트에 반영됩니다.
- 제출 오류가 발생해도 이미 적은 내용은 유지합니다.

## 참고 경험

[혁이네 레코드 신청 경험](https://hyuk-s-records.vercel.app/)의 다음 구조적 장점을 참고합니다.

- 첫 화면에서 바로 느껴지는 강한 브랜드 세계관
- 큰 한글 문장과 작은 상태 레이블의 대비
- 한 번에 하나의 질문에 집중하는 진행 방식
- 선택 즉시 바뀌는 전용 화면과 상태
- 처음부터 끝까지 이어지는 하나의 중심 메타포

음악, 레코드와 녹음실 표현은 사용하지 않습니다. 데이로그는 `내 하루를 쓰는 노트`라는 독자적인 메타포를 사용합니다.

## 핵심 콘셉트

### 콘셉트명

**LIFE NOTE: 짧은 선택으로 나의 하루를 적다**

### 중심 메타포

완벽한 계획표를 만들기 전에 지금의 하루를 적습니다.

- 각 질문은 노트의 한 페이지입니다.
- 선택지는 메모지, 체크박스와 밑줄처럼 보입니다.
- 질문 중에는 선택 답변 노트를 반복해서 보여주지 않습니다.
- 답변은 마지막 페이지에서 실제 노트 문장으로 정리됩니다.
- 마지막 결과는 진단표가 아니라 `나의 하루 초안`입니다.
- 오프라인 만남은 이 초안을 함께 읽고 다음 장을 쓰는 시간입니다.

### 지켜야 할 인상

- 손으로 쓴 듯 따뜻하지만 아마추어처럼 보이지 않습니다.
- 다이어리 꾸미기보다 기록과 대화에 집중합니다.
- 업무용 문서나 병원 문진표처럼 딱딱하지 않습니다.
- 과한 찢어진 종이, 낙서와 스티커 장식은 사용하지 않습니다.
- 선택을 점수, 유형 또는 평가로 표현하지 않습니다.

## 시각 언어

### 종이

- 기본 바탕은 Warm Ivory 종이색을 사용합니다.
- 아주 옅은 파란 가로줄로 노트의 기준선을 표현합니다.
- 왼쪽에는 낮은 채도의 붉은 세로 여백선을 사용합니다.
- 페이지 뒤에는 한두 장의 종이가 겹쳐진 듯한 얕은 그림자를 둡니다.

### 기록 도구

- 선택 전: 빈 체크박스 또는 페이지 번호
- 선택 후: 체크 표시, 노란 밑줄과 진한 잉크 문장
- 보조 안내: 옅은 노란 메모지
- 완료 상태: Sage Green 잉크의 기록 완료 도장

### 컬러 역할

| 컬러 | 역할 |
| --- | --- |
| Deep Navy | 잉크, 주요 문장, CTA와 체크 상태 |
| Growth Yellow | 형광펜, 밑줄, 선택 강조와 메모지 |
| Warm Ivory | 노트 종이와 전체 기록 공간 |
| Soft Beige | 종이 뒷면, 책상 위 보조 면과 구분 영역 |
| Sage Green | 기록 완료, 안정과 다음 변화 |

## 첫 화면

### 구성

- 바깥은 어두운 네이비 책상처럼 보입니다.
- 안쪽 전체는 한 권의 큰 노트처럼 구성합니다.
- 왼쪽에는 대표 문장과 시작 CTA를 둡니다.
- 오른쪽에는 기울어진 빈 하루 노트 한 장을 배치합니다.
- 화면 왼쪽에는 제본 구멍 또는 링을 암시하는 반복 요소를 둡니다.
- 코치 사진과 큰 인물 이미지는 사용하지 않습니다.

### 문구

작은 라벨:

`DAYLOG · A NOTE ABOUT MY DAY`

대표 문장:

> 당신의 하루를 한 장씩 적어볼게요.

설명:

잘 쓴 계획표가 아니어도 괜찮아요. 요즘의 리듬, 편안한 시간, 바꾸고 싶은 것을 짧게 적으며 첫 만남에서 나눌 이야기를 준비합니다.

CTA:

**내 하루 적고 신청하기 →**

보조 정보:

`5개의 짧은 선택 · 약 3분`

## 신청 흐름

### Page 00. 빈 노트

- 신청을 평가가 아니라 자기 기록의 시작으로 안내합니다.
- `3분간 하루를 기록하고 60분 오프라인 LIFE SESSION을 신청합니다.`라고 목적을 먼저 알립니다.
- 오른쪽 빈 노트에는 실제 질문과 일치하는 `오늘의 리듬`, `편안한 시간`, `바꾸고 싶은 한 가지` 기록 힌트를 보여줍니다.

### Page 01. 오늘의 리듬

질문:

> 요즘 하루는 어떤 리듬으로 흘러가나요?

선택한 내용은 마지막 `오늘의 리듬` 줄에 기록됩니다.

### Page 02. 하루의 온도

질문:

> 하루 중 가장 편안한 시간과 가장 힘든 시간은 언제인가요?

미선택 상태가 있는 접근 가능한 시간 선택 목록을 사용하며 두 시간은 마지막 노트에 기록됩니다.

### Page 03. 오래간 것의 이유

질문:

> 오래 이어가 본 일이 있나요?

성취를 평가하지 않고 지속을 도왔던 조건을 기록합니다.

### Page 04. 바꾸고 싶은 한 줄

질문:

> 지금 가장 먼저 바꾸고 싶은 곳은 어디인가요?

1~3개의 생활 영역을 선택하고 그중 첫 번째로 이야기할 영역 하나를 표시합니다.

### Page 05. 함께하는 방법

질문:

> 어떤 방식이면 조금 더 오래 이어갈 수 있을까요?

코치에게 기대하는 정답이 아니라 자신에게 도움이 되는 동행 방식을 기록합니다.

### 마지막 페이지. 나의 하루 초안

고객이 선택한 내용을 한 장의 노트로 정리합니다.

- 오늘의 리듬
- 편안한 시간과 버거운 시간
- 계속할 수 있었던 방식
- 먼저 바꾸고 싶은 곳
- 함께하고 싶은 방식

완성 노트는 진단 결과가 아니라 **첫 만남에서 함께 읽고 이어 쓸 초안**이라고 안내합니다.

CTA는 `이야기 이어가기`로 표시합니다.

CTA 바로 아래에는 다음 단계가 `이름과 연락처를 남기는 신청 단계`임을 미리 안내합니다.

## 선택 카드

### 기본 상태

- 직각에 가까운 종이 조각 형태
- 옅은 가로 노트선
- 페이지 번호 또는 빈 체크 표시
- 큰 선택 문장과 짧은 설명
- 접근 가능한 실제 라디오 또는 체크 입력 유지

### 선택 상태

- Deep Navy 체크 표시
- Growth Yellow 메모지 배경 또는 형광펜 밑줄
- 얕은 종이 그림자
- 색상 외에도 체크와 텍스트 변화로 상태 전달

### Hover와 Focus

- 종이가 1~2px 들리는 정도의 짧은 움직임
- Growth Yellow 포커스 링
- 기울기와 그림자를 과하게 사용하지 않습니다.

## 연락 신청 페이지

연락 정보도 별개의 일반 폼처럼 보이지 않게 같은 노트 세계관을 유지합니다.

- 필수 입력은 이름·호칭, 연락 방법, 연락처와 개인정보 동의입니다.
- 희망 요일, 희망 시간대와 추가 이야기는 선택 입력으로 표시합니다.
- 필수와 선택을 각 레이블에서 명확히 구분합니다.
- 섹션 번호는 작은 인덱스 스탬프로 표시합니다.
- 한 줄 입력은 노트의 빈 밑줄처럼 표현합니다.
- 추가 이야기는 여러 줄 메모 영역처럼 표현합니다.
- 개인정보 동의는 노란 메모지 위 체크 항목으로 표현합니다.
- 왼쪽에는 `60분 1:1 LIFE SESSION` 메모를 배치합니다.

민감한 생활 정보는 온라인에서 추가로 묻지 않고 직접 만남에서 다룹니다.

제출 CTA는 화면에서 바로 찾을 수 있는 위치에 두며, 선택 정보가 비어 있어도 필수 정보만 충족하면 신청할 수 있어야 합니다.

## 완료 화면

- 완료 상태는 Sage Green `기록 완료` 도장으로 표시합니다.
- 접수번호는 작은 보관 메모처럼 표시합니다.
- 문구는 `이제 직접 만나 함께 살펴볼게요.`를 유지합니다.

## 반응형

| 너비 | 구성 |
| --- | --- |
| 840px 이상 | 중앙 단일 열 질문과 2열 선택 카드 |
| 600~839px | 중앙 단일 열 질문과 폭에 맞춘 선택 카드 |
| 599px 이하 | 일반 선택 1열, 생활 영역 2열 구성 |
| 599px 이하·높이 700px 이하 | 생활 영역만 제목 중심 3열 구성 |

- 작은 화면에서도 질문 문장과 체크 상태가 먼저 읽혀야 합니다.
- 노트의 장식보다 입력과 CTA를 먼저 보여줍니다.
- 모바일 키보드가 입력과 제출 버튼을 가리지 않게 합니다.

## 모션

- 질문 전환: 짧은 페이지 이동처럼 360ms 안에 페이드와 작은 수직 이동
- 선택 반응: 카드 테두리, 체크와 얇은 Yellow 선이 바뀌는 140~180ms 변화
- CTA Hover: 종이 그림자가 한 단계 커지는 움직임
- 반복 회전과 장식용 무한 모션은 사용하지 않습니다.
- 모션 감소 설정에서는 즉시 상태가 바뀌도록 합니다.

## 접근성

- 노트 장식은 의미 없는 배경으로 처리합니다.
- 최종 노트는 텍스트 목록으로도 읽을 수 있어야 합니다.
- 색만으로 선택과 완료를 구분하지 않습니다.
- 실제 라디오, 체크박스, 범위 입력과 폼 레이블을 유지합니다.
- 장면 이동 후 질문 제목으로 포커스를 옮깁니다.
- 44×44px 이상의 터치 영역과 충분한 명도 대비를 유지합니다.

## 이미지와 에셋

초기 버전은 별도 사진이나 일러스트 없이 CSS 기반 종이, 줄, 테이프, 체크와 도장으로 구현합니다.

- 코치 사진을 첫 화면에 배치하지 않습니다.
- 기존 `application-form-hero-v1.png`는 방향 탐색 기록으로만 보관합니다.
- 실제 종이 질감 이미지는 성능과 가독성 검토 후 필요한 경우에만 추가합니다.
