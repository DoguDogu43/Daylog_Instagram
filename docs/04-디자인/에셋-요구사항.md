# 디자인 및 구현 에셋 요구사항

## 문서 목적

홈페이지 구현과 리플렛 제작을 시작하기 전에 받아야 할 자료와 결정 사항을 정리합니다.

## 우선순위

- **P0:** 디자인 확정 또는 구현 시작에 반드시 필요
- **P1:** 초기 구현은 임시 자료로 가능하지만 공개 전 필요
- **P2:** 후속 개선 단계에서 추가 가능

## 마룬이 비주얼 납품 기준

신청 폼용 첫 시안은 구현 저장소의 `assets/brand/application-form-hero-v1.png`에 보관합니다. 이 파일은 첫 번째 방향 탐색 기록이며 최종 신청 경험의 중심 이미지로 사용하지 않습니다. 최종 방향은 [신청 경험 디자인](신청-폼-디자인.md)의 LIFE NOTE와 한 줄씩 채워지는 기록 인터랙션입니다.

### 필수 장면

1. 정장을 입은 남녀가 함께 고객을 맞이하는 장면
2. 남성 단독 기본 포즈
3. 여성 단독 기본 포즈
4. 함께 하루를 펼쳐보는 장면
5. 작은 행동을 안내하는 장면
6. 완성된 하루 노트를 함께 읽는 장면
7. 리플렛 앞면에 사용할 세로 또는 중앙 집중형 장면

### 신청 경험 그래픽

- LIFE NOTE 페이지 프레임
- 시간대별 기록 줄과 선택 상태
- 생활 영역 9개 카드 아트
- Growth Yellow 밑줄·체크 그래픽
- Sage Green 완료 상태
- Warm Ivory 종이 질감
- 단계 전환용 페이지 넘김·한 줄 작성 그래픽

### 파일 형식

- 벡터 일러스트라면 SVG 또는 원본 편집 파일
- 래스터 이미지라면 투명 배경 PNG
- 웹용 WebP 또는 AVIF 파생본
- 인쇄용은 최종 사용 크기 기준 300ppi 이상
- 인물과 배경이 분리된 레이어 또는 개별 파일

### 권장 구성

- 정장은 Deep Navy 계열
- Growth Yellow와 Sage Green은 소품 또는 작은 그래픽에 제한
- 표정은 따뜻하고 자연스럽게 구성
- 지시하거나 평가하는 자세보다 환대하거나 함께 보는 자세
- 모바일 크롭을 고려해 얼굴과 손이 안전 영역 안에 위치

## 문구 결정이 필요한 부분

### Hero 대표 문장 후보

1. `당신의 하루를 함께 봅니다.`
2. `당신에게 맞는 하루를 설계합니다.`
3. `혼자 바꾸기 어려운 하루, 같이 바꿉니다.`

한 문장을 대표 H1으로 선택하고 나머지는 보조 문구나 다른 섹션에 배치합니다.

### CTA 후보

1. `나의 루틴 만나보기 →`
2. `내 하루 이야기하기`
3. `Life Session 신청하기`

CTA는 실제 연결 행동에 맞춰 선택합니다. 예약 화면으로 바로 이동한다면 `Life Session 신청하기`가 가장 명확하고, 서비스 설명으로 이동한다면 `나의 루틴 만나보기`를 사용할 수 있습니다.

## 권리 확인

- 이미지, 캐릭터, 로고와 서체의 상업적 사용 권한을 확인합니다.
- AI 생성 이미지를 사용하는 경우 생성 출처와 후속 편집 가능 여부를 기록합니다.
- 실제 인물 사진은 웹, 인쇄와 광고 채널별 초상권 동의를 확인합니다.
- 고객 후기와 사례는 공개 범위와 표기 방식에 관한 동의를 기록합니다.
