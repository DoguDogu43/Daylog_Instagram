# 실행·회고·재설계

## 정의

고객이 설계한 행동을 실제 생활에서 시도하고, 다시 만나 그 경험을 이야기하며, 더 적합한 방식으로 수정하는 반복 과정입니다.

서비스는 루틴을 만든 순간이 아니라 고객이 생활로 돌아간 순간부터 본격적으로 시작됩니다.

## 1. 실행: 직접 살아보기

고객은 자신의 생활로 돌아가 설계한 행동을 실제로 시도합니다.

계획대로 되는 날도 있고 그렇지 않은 날도 있습니다. 이 단계의 목적은 모든 행동을 완벽하게 지키는 것이 아니라 **루틴이 실제 생활에서 어떻게 작동하는지 알아보는 것**입니다.

### 실행 중 살펴볼 경험

- 어떤 날과 상황에서 자연스럽게 실행되었나요?
- 시작하기 쉬웠던 조건은 무엇인가요?
- 어느 순간 하기 싫거나 포기하고 싶었나요?
- 예상하지 못한 방해 요인이 있었나요?
- 생각보다 쉬웠거나 어려웠던 부분은 무엇인가요?
- 행동 전후에 어떤 감정이나 생각이 들었나요?

## 2. 회고: 다시 만나기

두 번째 만남은 다음 질문에서 시작합니다.

> 직접 해보니 어땠어요?

"몇 개 성공했어요?"보다 경험을 먼저 묻습니다. 성공 여부만으로 고객이나 계획을 평가하지 않습니다.

### 회고 질문

- 잘된 날에는 무엇이 달랐나요?
- 실행하기 싫었던 이유는 무엇이었나요?
- 생각보다 쉬웠나요, 어려웠나요?
- 어느 순간 포기하고 싶었나요?
- 시간이나 장소는 적절했나요?
- 행동의 크기는 적당했나요?
- 계속하고 싶은 부분은 무엇인가요?
- 바꾸거나 없애고 싶은 부분은 무엇인가요?

### 회고 원칙

- 성공과 실패를 같은 가치의 데이터로 봅니다.
- 고객의 설명보다 코치의 해석을 앞세우지 않습니다.
- 실행하지 못한 이유를 의지 부족으로 결론 내리지 않습니다.
- 계획이 맞지 않았을 가능성을 열어둡니다.
- 고객이 느낀 감정과 현실적인 제약을 함께 봅니다.

## 3. 재설계: 함께 수정하기

실제 경험을 바탕으로 루틴을 더 적합하게 수정합니다.

### 조정할 수 있는 요소

- 행동의 크기나 횟수
- 실행 시간
- 실행 장소
- 시작 신호
- 행동의 순서
- 어려운 날의 최소 기준
- 주변 사람과의 약속 또는 도움
- 방해 요인을 줄이는 환경
- 행동 자체의 유지, 교체 또는 제거

### 재설계 질문

- 그대로 유지할 부분은 무엇인가요?
- 너무 크거나 어려웠던 부분은 무엇인가요?
- 더 자연스러운 시간이나 장소가 있나요?
- 시작을 쉽게 만들려면 무엇이 필요할까요?
- 이번에는 어느 정도로 바꿔서 시도해 볼까요?

## 4. 반복: 다시 살아보기

수정한 방식으로 다시 실행합니다. 이후 다시 만나 경험을 이야기하고 필요한 부분을 조정합니다.

**실행 → 회고 → 재설계 → 재실행**을 반복하면서 고객에게 맞는 생활 방식을 찾아갑니다.

## 반복 과정의 목표

- 고객이 자신의 생활 패턴을 더 잘 이해합니다.
- 자신에게 맞는 변화의 크기와 조건을 발견합니다.
- 실패를 자책보다 학습의 재료로 다룹니다.
- 코치 없이도 스스로 점검하고 조정하는 힘을 기릅니다.
