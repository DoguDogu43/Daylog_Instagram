# 데이로그 서비스 흐름

## 전체 흐름

**직접 만난다 → 이야기를 듣는다 → 사람을 이해한다 → 함께 루틴을 만든다 → 직접 살아본다 → 다시 만난다 → 함께 수정한다**

영문 단계명으로는 다음과 같이 표현합니다.

**Meet → Discover → Design → Live → Meet Again → Redesign → Repeat**

이 흐름에서 어느 하나도 분리하지 않습니다. 직접 만나는 것만으로 끝나지 않고, 계획을 만드는 것만으로도 끝나지 않습니다. 실제 생활에서 얻은 경험을 다시 대화로 가져와 함께 수정하는 반복 구조가 데이로그의 핵심입니다.

## 단계별 흐름

### 1. Meet: 직접 만난다

온라인 응답만으로 고객을 판단하지 않습니다. 한 사람과 마주 앉아 대화를 시작합니다.

**핵심 질문**

- 요즘 어떻게 지내세요?
- 요즘 하루는 어떻게 보내세요?
- 무엇 때문에 힘든가요?
- 무엇을 바꾸고 싶나요?

**다음 단계로 가져가는 것**

- 고객이 중요하게 생각하는 이야기
- 현재 생활에 관한 첫 인상
- 더 깊게 살펴볼 주제

### 2. Discover: 이야기를 듣고 사람을 이해한다

현재의 행동만 보지 않고 과거의 경험, 지속했던 일, 중단했던 이유와 원하는 삶을 살펴봅니다.

**발견하는 것**

- 생활 리듬과 반복되는 패턴
- 행동을 돕는 조건과 방해하는 조건
- 고객이 움직이는 방식
- 고객이 원하는 변화와 그 이유

**연결되는 단계**

- [Life Interview](라이프-인터뷰.md)
- [Life Mapping](라이프-매핑.md)

### 3. Design: 함께 루틴을 만든다

코치가 일방적으로 정하지 않습니다. 고객이 가장 먼저 바꾸고 싶은 영역을 선택하고, 현재 생활에서 실행할 수 있는 핵심 행동 1~3개를 함께 정합니다.

**설계 기준**

- 구체적인가?
- 실제 생활에서 가능한가?
- 너무 많은 변화를 한꺼번에 요구하지 않는가?
- 고객이 스스로 선택하고 동의했는가?
- 실행 후 경험을 확인할 수 있는가?

자세한 내용은 [My Routine Design](루틴-설계.md)을 참고합니다.

### 4. Live: 직접 살아본다

고객은 자신의 생활로 돌아가 설계한 행동을 실제로 시도합니다. 계획대로 되는 날과 되지 않는 날을 모두 경험합니다.

이 단계의 목적은 완벽하게 지키는 것이 아니라 **이 루틴이 실제 생활에서 어떻게 작동하는지 알아보는 것**입니다.

**가져올 경험**

- 잘된 순간과 그 조건
- 시작하기 어려웠던 순간
- 예상보다 쉬웠거나 어려웠던 점
- 계획과 실제 생활이 달랐던 부분
- 행동하면서 느낀 감정과 생각

### 5. Meet Again: 다시 만난다

다음 만남은 "몇 개 성공했어요?"가 아니라 "직접 해보니 어땠어요?"라는 질문에서 시작합니다.

성공률보다 고객의 경험을 먼저 듣고, 행동이 실제 생활에서 작동한 방식과 작동하지 않은 이유를 함께 해석합니다.

### 6. Redesign: 함께 수정한다

첫 번째 루틴을 정답으로 고수하지 않습니다. 고객의 실제 경험을 바탕으로 행동의 크기, 시간, 장소, 조건이나 우선순위를 수정합니다.

수정은 실패의 결과가 아니라 서비스의 정상적인 과정입니다.

### 7. Repeat: 다시 살아본다

수정한 방식을 고객이 다시 생활에서 시도합니다. 이후 다시 만나 경험을 듣고 필요한 부분을 조정합니다.

**실행 → 만남 → 재설계**의 반복을 통해 고객에게 맞는 생활 방식을 찾아갑니다.

## 반복 구조의 의미

- 계획을 정답이 아니라 가설로 다룹니다.
- 고객의 실제 생활을 가장 중요한 근거로 사용합니다.
- 실패를 의지의 문제가 아니라 설계 데이터로 봅니다.
- 코치와 고객이 함께 해석하고 함께 결정합니다.
- 반복할수록 고객이 자신의 패턴을 더 잘 이해하도록 돕습니다.
- 궁극적으로 고객이 스스로 점검하고 설계할 수 있게 합니다.

## 단계별 핵심 문장

| 단계 | 고객에게 건네는 문장 |
| --- | --- |
| Meet | 요즘 어떻게 지내세요? |
| Discover | 그때는 무엇이 달랐나요? |
| Design | 가장 먼저 바꾸고 싶은 곳은 어디인가요? |
| Live | 이번 주에는 직접 살아봅니다. |
| Meet Again | 직접 해보니 어땠어요? |
| Redesign | 지금 생활에 더 잘 맞게 바꿔볼까요? |
| Repeat | 수정한 방식으로 다시 시도해 봅니다. |
